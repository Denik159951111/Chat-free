# Chat-free

Простой и быстрый веб-чат на Streamlit с бесплатными нейросетями через OpenRouter.

Сделан в темном минималистичном стиле без лишних элементов.

### Что есть:
- Бесплатные модели: NVIDIA Nemotron 3 Ultra, Gemma 4, MiniMax и другие (автоматически подтягиваются через API).
- Потоковый вывод сообщений (стриминг в реальном времени).
- Сохранение истории в браузере — если закрыть вкладку или перезапустить браузер, переписка остается.
- Стартовый экран-хаб для удобного запуска и навигации.

### Как запустить локально:
1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. В файле `.streamlit/secrets.toml` указать свой ключ:
   ```toml
   OPENROUTER_API_KEY = "sk-or-v1-..."
   ```
3. Запустить проект:
   ```bash
   streamlit run app.py
   ```
