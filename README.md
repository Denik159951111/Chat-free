# ⚡ NEXUS // MONO — Streamlit Dark AI Chatbot

Ультрасовременный чат-бот на базе **Streamlit** и **OpenRouter API** в строгом монохромном темном стиле (Obsidian / Stealth Dark).

## 🌟 Особенности
- **Динамический список бесплатных нейросетей**: приложение автоматически подтягивает все бесплатные модели из OpenRouter (`NVIDIA: Nemotron 3 Ultra (free)`, `NVIDIA: Nemotron 3.5 Lightning`, `Google: Gemma 4`, `MiniMax M3`, `Cohere North Mini`, `Poolside Laguna` и др.).
- **Модель по умолчанию**: `NVIDIA: Nemotron 3 Ultra (free)` с контекстным окном 1 000 000 токенов и архитектурой MoE (550B параметров).
- **Поддержка рассуждений (Reasoning / CoT)**: для моделей линейки Nemotron ход мыслей выводится в элегантный сворачиваемый блок.
- **Премиальный темный визуал**:
  - Цветовая палитра: глубокий графит, обсидиан и матовый титан (`#07080b`, `#0e1117`, `#141720`).
  - Полное отсутствие разноцветных радужных элементов.
  - Современная типографика (Google Font `Plus Jakarta Sans` и `JetBrains Mono`).
  - Плавные микроанимации, стеклянные карточки сообщений, стилизованное поле ввода.
- **Пресеты системных промптов**: Универсальный помощник, Архитектор кода, Глубокое рассуждение, Аналитик, Краткий режим.
- **Управление сессией**: очистка истории в 1 клик, экспорт беседы в `.md`.

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
streamlit run app.py
```
или просто дважды кликните по файлу `run.bat`.

Приложение откроется в браузере по адресу: [http://localhost:8501](http://localhost:8501)
